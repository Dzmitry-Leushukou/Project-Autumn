## Явные границы результата

Обычный поиск воспроизводим при том же seed/настройках/версиях библиотек.
Аварийный time_budget_s остаётся ограничением реального времени: результат только из
полностью оценённых кандидатов явно имеет `reproducible=false` и предупреждение в интерфейсе.
При нехватке времени даже для исходного сценария возвращается понятная ошибка.
Одновременно обещать одинаковый объём работы и произвольный wall-clock предел на любой
машине невозможно; завершение процессов также требует небольшого служебного времени.
Это отличается от прежнего скрытого выбора нормального объёма поиска по времени.

Станционный флаг дверей Waterloo всё ещё влияет также на Bakerloo: это ограничение
заданного формата 1.0, явно описанное в интерфейсе и аудите. Реальные назначения и прогноз
нагрузки TfL не заявляются. Сохраняется одно не блокирующее предупреждение об устаревшем
алиасе в стороннем Starlette TestClient; тесты не пропускаются и предупреждение не подавляется.

Новый удалённый GitHub Actions в этой работе не запускался: переносимость проверена
локально в Linux, а конфигурация CI обновлена. Временные копии установки игнорируются Git
и не входят в поставку; исходное ограничение удаления из первого аудита не обходилось.
